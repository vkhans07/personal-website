# Vijay Kumar Hans — personal website

React + Vite recreation of the supplied HTML design reference. The person-facing portfolio is in `src/main.jsx`; styles are in `src/styles.css`.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The Word Hunt dialog is presentation only. See `server/README.md` for the suggested API seam and implementation notes. The attention effect is intentionally left as a TODO in the app.
